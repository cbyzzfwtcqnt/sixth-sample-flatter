## Overview

F(l)atter uses AI pitch detection to apply transparent pitch correction to lead vocals and harmonies with formant correction, vibrato control, and manual note correction on an on-screen piano roll.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sixth Sample Flatter** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **AI Pitch Detection** | Neural pitch detection handles complex melismatic vocal runs |
| **Formant Correction** | Independent formant shifting preserves natural voice character |
| **Vibrato Control** | Adjust natural vibrato rate and depth independently from pitch |
| **Piano Roll Editor** | Manually correct individual notes on the on-screen note editor |
